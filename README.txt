СЕРВЕР ТОХИРУУЛАХ (EEA306-тай адил, шинээр нэг удаа)
  1. Google Drive → шинэ Google Sheets үүсгэнэ (жишээ нь «EEA721 дүн»).
  2. Extensions → Apps Script → Code.gs-ийн агуулгыг хуулж тавина.
  3. Project Settings → Script Properties → PW = багшийн нууц үг.
  4. seedRoster функцийг ▶ Run (зөвшөөрөл өгнө: Sheets ба Drive).
     Жагсаалтыг дараа нь вэбийн «Тохиргоо» хэсгээс Excel-ээс хуулж оруулж болно.
  5. Deploy → New deployment → Web app; Execute as: Me; Who has access: Anyone.
  6. Гарсан https://script.google.com/macros/s/…/exec хаягийг index.html доторх
     const API_URL = "";  мөрөнд хашилтын дотор тавина.
  API_URL хоосон үед вэб «зочин» горимд ажиллана (бүх материал үзэгдэх ч дүн хадгалагдахгүй).

БИЕ ДААЛТ
  • 6 ажил × 5 оноо = 30 оноо. Хувилбар = EEA721_Оюутан хуудсан дахь оюутны дараалал (1–10); 10 хүртэл оюутан бүр өөр өгөгдөлтэй. БД-5 (АС ба ACCC), БД-6 (СИП-2) жишээ бодолттой.
  • Оюутан «Ажлын талбар»-т тооцоогоо бичнэ (автоматаар хадгална), тооцоолуур ашиглана,
    тайлангийн файлаа (PDF/Word/Excel/ZIP/зураг, 8 МБ хүртэл) хавсаргаж илгээнэ.
  • Файл Drive-ийн «EEA721_Бие_даалт» хавтаст, бичвэр Sheets-ийн «BD» хуудсанд хадгалагдана.
  • Багш «Оюутны дүн» → оюутны нэр дээр дарж, БД бүрийг үзэн дүн (0–5), тайлбар оруулна.
    Дүгнэсэн ажлыг оюутан дахин илгээх боломжгүй; дүгнээгүй бол дахин илгээж болно (сүүлийнх нь тооцогдоно).
  • Word хувилбар: docs/EEA721_Bie_daalt.docx (бие даалт), docs/EEA721_Test_120.docx (тест, лекц бүрийн зөв хариулттай).
